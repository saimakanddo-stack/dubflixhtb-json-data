# JSON Structure Documentation

## Overview
এই ডকুমেন্টেশনে JSON এর সম্পূর্ণ structure, প্রতিটি field এর উৎস এবং ব্যবহার বিস্তারিতভাবে বর্ণনা করা হয়েছে।

---

## JSON Schema Structure

### Root Level
JSON একটি **Array** যেখানে প্রতিটি element একটি movie/series object।

```json
[
  {
    // Movie Object Fields
  },
  {
    // Another Movie Object
  }
]
```

---

## Field-by-Field Documentation

### 1. **id** (String)
- **Type**: `string`
- **Format**: `{type}{serial}` (e.g., `"movie1"`, `"series2"`, `"webseries5"`)
- **Source**: Auto-generated by JavaScript
- **Generation Logic**: 
  - Function: `generateNextId(type)` (lines 1502-1521)
  - Uses `info4_type` to determine prefix
  - Serial number auto-increments per type
  - Checks for duplicates to avoid conflicts
- **Used In**: 
  - Unique identifier for each movie/series
  - Duplicate detection
  - Data management

### 2. **post_url** (String)
- **Type**: `string` (URL)
- **Source**: Target website থেকে scraped
- **Scraping Element**: 
  - Selector: `.image-container a[href]`
  - Function: `parseMovieCard()` line 1722
  - Resolved to absolute URL using `resolveUrl()`
- **Used In**:
  - Direct link to movie detail page
  - Duplicate detection (comparison)
  - User navigation

### 3. **title** (String)
- **Type**: `string`
- **Source**: Multiple sources (priority order):
  1. Detail page heading: `.mb-2.font-bold.text-center.text-xl, h1, .post-title`
  2. List page link text
  3. Image `alt` attribute
- **Scraping Elements**:
  - **List Page**: `.mb-2.font-bold, .card-title, .title, h3, h2` (line 1731)
  - **Detail Page**: `.mb-2.font-bold.text-center.text-xl, h1, .post-title, .md\\:text-3xl` (line 1775)
- **Processing**: `cleanMovieTitle()` function (line 1490-1494)
  - Normalizes whitespace
  - Trims extra spaces
- **Used In**:
  - Display title in UI
  - Duplicate detection (fallback)
  - User-facing content

### 4. **check_title** (String)
- **Type**: `string`
- **Source**: Longest/most detailed title from all available sources
- **Scraping Elements**: Collects from:
  - Link text
  - Link `title` attribute
  - Heading text
  - Image `alt` attribute
  - Image `title` attribute
- **Selection Logic**: 
  - Chooses longest string (line 1742)
  - More detailed for accurate duplicate detection
- **Used In**:
  - **Primary duplicate detection** (line 1538-1551)
  - Ensures unique entries
  - Status comparison

### 5. **imageUrl** (String)
- **Type**: `string` (URL)
- **Source**: Target website image
- **Scraping Elements**:
  - **List Page**: `img[src]` (line 1744)
  - **Detail Page**: `.image-container-view img[src]` (line 1770-1772)
- **Processing**: Resolved to absolute URL
- **Used In**:
  - Movie poster display
  - Duplicate detection (image match)
  - Visual identification

### 6. **info1_custom** (String)
- **Type**: `string`
- **Default**: `""` (empty)
- **Source**: Not scraped, manually set
- **Used In**: Custom information field

### 7. **info2_quality** (String)
- **Type**: `string`
- **Source**: Detail page info section
- **Scraping Element**: 
  - Pattern: `<b>Quality:</b> {value}`
  - Function: `extractInfoValue(html, 'Quality')` (line 1807)
  - Regex: `/<(b|strong)\s*Quality\s*:?\s*<\/\1>\s*([^<]+)/i`
- **Example Values**: `"BluRay"`, `"WEB-DL"`, `"HDRip"`
- **Used In**:
  - Quality indicator
  - Duplicate detection
  - Filtering

### 8. **info3_language** (String)
- **Type**: `string`
- **Source**: Detail page, normalized
- **Scraping Element**: 
  - Pattern: `<b>Language:</b> {value}`
  - Function: `extractInfoValue(html, 'Language')` (line 1805)
- **Processing**: `normalizeLanguage()` function (line 1475-1488)
  - Replaces "Dual" with "Dual Audio"
  - Converts `[]` and `–` to commas
  - Cleans multiple commas
- **Example**: `"Hindi, English"` → `"Hindi, English"`
- **Used In**:
  - Language display
  - Duplicate detection

### 9. **info4_type** (String)
- **Type**: `string`
- **Source**: Detail page
- **Scraping Element**:
  - Pattern 1: `<b class="text-orange">{value}</b>` (line 1796)
  - Pattern 2: `<b>Type:</b> {value}`
  - Default: `"Movie"`
- **Example Values**: `"Movie"`, `"Series"`, `"Web Series"`
- **Used In**:
  - ID generation prefix
  - Type classification
  - Duplicate detection
  - Filtering

### 10. **language_info** (String)
- **Type**: `string`
- **Source**: Raw language value (before normalization)
- **Scraping Element**: Same as `info3_language` but unprocessed
- **Used In**:
  - Original language information
  - Duplicate detection

### 11. **info_subtitle** (String)
- **Type**: `string`
- **Default**: `""` (empty)
- **Source**: Not scraped, manually set
- **Used In**: Subtitle information

### 12. **info6_status** (String)
- **Type**: `string`
- **Source**: Detail page status badge
- **Scraping Element**:
  - Selectors (priority order):
    1. `.badge.ep-badge.added` (line 1816)
    2. `.badge.ep-badge`
    3. `.badge.status`
  - Scoped to content area: `.data, .sheader, .extra, .mvic-desc`
- **Processing**: Whitespace normalization (line 1823)
- **Example Values**: 
  - `"Online"`
  - `"S01 | Ep 1-9 Added"`
  - `"HD"`
  - `"Completed"`
- **Used In**:
  - Status display
  - **Duplicate detection with season/episode logic** (line 1571-1600)
  - Update detection

### 13. **enablePosterBlur** (Boolean)
- **Type**: `boolean`
- **Source**: Adult content badge detection
- **Scraping Element**: 
  - Selector: `.badge.adult18plus-badge` (line 1717)
  - Checks entire card HTML
- **Logic**: 
  - `true` if adult badge found
  - `false` otherwise
- **Used In**:
  - Content filtering
  - UI blur effect

### 14. **blurPercentage** (Number)
- **Type**: `number`
- **Default**: `10`
- **Source**: Static value
- **Used In**: Blur intensity control

### 15. **imdb** (String)
- **Type**: `string`
- **Source**: Detail page
- **Scraping Element**:

  - Function: `extractInfoValue(html, 'IMDb')` (line 1803)
- **Example**: `"8.5/10"`
- **Used In**: IMDb rating display

### 16. **genre** (String)

### 17. **resolution** (String)

- **Scraping Element**:

### 20. **storyline** (String)
- **Type**: `string`
- **Source**: Detail page
- **Scraping Element**: 
  - Selector: `.storyline-box.mt-2 .story-text` (line 1793)

- **Used In**:

  - Duplicate detection

### 21. **visibility** (String)
- **Type**: `string`
- **Default**: `"published"`
- **Source**: Static value
- **Used In**: Publication status

### 22. **total_views** (Number)
- **Type**: `number`
- **Default**: `0`
- **Source**: Static initial value
- **Used In**: View counter

### 23. **createdAt** (String - ISO Date)
- **Type**: `string` (ISO 8601 format)
- **Source**: Upload time from detail page
- **Scraping Element**: 
  - Selector: `.upload-time` (line 1826)
- **Processing**: `parseUploadTime()` function (line 1420-1473)
  - Parses "X hours/days/weeks ago" format
  - Converts to ISO timestamp
- **Example**: `"2024-02-03T10:30:00.000Z"`
- **Used In**: Creation timestamp

### 24. **lastUpdated** (String - ISO Date)
- **Type**: `string` (ISO 8601 format)
- **Source**: Same as `createdAt` (line 1829)
- **Used In**: Last update timestamp

### 25. **server** (Boolean)
- **Type**: `boolean`
- **Default**: `true`
- **Source**: Static value
- **Used In**: Server availability flag

### 26. **server_info** (String)
- **Type**: `string`
- **Default**: `""` (empty)
- **Source**: Not scraped
- **Used In**: Server information

### 27-32. **runtime, director, writer, rated, trailer** (Strings)
- **Type**: `string`
- **Default**: `""` (empty)
- **Source**: Not currently scraped
- **Used In**: Additional movie metadata

### 33. **info5_views** (Number)
- **Type**: `number`
- **Default**: `0`
- **Source**: Static value
- **Used In**: View counter (alternative)

### 34. **screenshotLinks** (Array of Strings)
- **Type**: `array` of `string` (URLs)
- **Source**: Detail page screenshot gallery
- **Scraping Element**: 
  - Selector: `.screenshot-wrapper [data-src]` (line 1786)
  - Attribute: `data-src`
- **Processing**: Resolved to absolute URLs
- **Example**: 
  ```json
  [
    "https://example.com/screenshot1.jpg",
    "https://example.com/screenshot2.jpg"
  ]
  ```
- **Used In**: Screenshot gallery display

### 35. **downloadOptions** (Array of Objects)
- **Type**: `array` of download server objects
- **Structure**:
  ```json
  [
    {
      "server": "G-Drive",
      "server_info": "",
      "qualities": [
        {
          "quality_text": "1080p",
          "path": "https://...",
          "file_size": "2.5 GB"
        }
      ],
      "labels": []
    }
  ]
  ```

#### 35.1. **server** (String)
- **Default**: `"G-Drive"`
- **Source**: Static value
- **Used In**: Server name display

#### 35.2. **server_info** (String)
- **Default**: `""` (empty)
- **Used In**: Server details

#### 35.3. **qualities** (Array)
- **Source**: Download links from detail page
- **Scraping Elements**:
  - Selectors (line 1833-1836):
    1. `.d-flex.justify-content-center.align-items-center.my-2 .d-flex.flex-wrap.justify-content-center.align-items-center.gap-2.gap-md-3.my-2 a[href*="/getLink/"]`
    2. `.card.h-100.border-left-success.shadow-sm.position-relative .mb-2.d-flex.justify-content-center a[href*="/getLink/"]`
  - Pattern: `Download [{quality} • {size}]` (line 1841)

##### 35.3.1. **quality_text** (String)
- **Source**: Extracted from download link text
- **Example**: `"1080p"`, `"720p"`, `"480p"`

##### 35.3.2. **path** (String - URL)
- **Source**: Link `href` attribute
- **Processing**: Resolved to absolute URL
- **Example**: `"https://example.com/getLink/abc123"`

##### 35.3.3. **file_size** (String)
- **Source**: Extracted from download link text
- **Example**: `"2.5 GB"`, `"850 MB"`

#### 35.4. **labels** (Array)
- **Default**: `[]` (empty array)
- **Used In**: Additional labels/tags

## Data Flow Direction

### From Target Site → JSON
All scraped fields flow from target website elements to JSON structure through the scraping functions.

### From JSON → UI Display
JSON data is displayed in the live viewer and can be:
- Copied to clipboard
- Downloaded as file
- Merged with existing data
- Filtered (new only vs. full)
